02 · Course Alignment

How CITYPULSE Matches Our ML Syllabus

Every module from our B.Tech Machine Learning course mapped directly to where it is implemented in this project.

Syllabus Course Topic Where Used in CITYPULSE
Module I Supervised & Unsupervised Learning, Data Types, Stats & EDA Supervised: Traffic speed regression (LightGBM, GRU), Crisis classification, PM2.5 forecasting.
Unsupervised: Isolation Forest anomaly detection (step17).
Stats & EDA: Mean, std, 85th percentile free-flow, missing %, and EDA plots with matplotlib (step02, step03).
Module II Preprocessing, Missing Values, Train/Test Split, Scaling, Outlier Detection, Regression Metrics Cleaning: Impossible speeds (<0 or >120 mph) removed, short gaps interpolated, missing mask kept (step03).
Time Split: Strict 70% train / 10% val / 20% test split + leakage test (step07, step08).
Scaling: StandardScaler fit on train only; speed_ratio normalization.
Metrics: MAE and RMSE evaluated across all horizons (step09–step13, step18).
Module III Classification, Precision/Recall/F1, Tree Models, Bias-Variance, Overfitting Classification: City crisis warning (>30% sensors congested for ≥30m) using LightGBM Classifier (step17).
Metrics: Precision (0.853), Recall (0.972), F1-Score (0.909), PR-AUC (0.981).
Overfitting Control: Validation early stopping & train-vs-val loss curves (step10, step11, step12).
Module IV Sparsity, High-Dimensional Data, Graph / Distance Matrices Graph & Sparsity: Road-network shortest travel-time matrix with Gaussian kernel producing a 63.9% sparse 50×50 adjacency matrix (step06), used in Graph+GRU (step12).
